# Contributing to Blankspace

Thanks for checking out Blankspace.

## Before contributing

- Test configuration changes on Hyprland when possible.
- Keep the black-and-white, distraction-free direction intact.
- Avoid committing personal paths, secrets, cache files, or backup files.
- Keep configuration changes focused and easy to understand.

## Suggestions

Open an issue with a short description of the idea, why it helps, and which component it affects.

## Pull requests

For a pull request, explain what changed and include screenshots when the visual result is relevant.
