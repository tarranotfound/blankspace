# Prefer Standard Algorithms

Standard algorithms express intent and reduce hand-written loop logic.

```cpp
auto count = std::count(values.begin(), values.end(), target);
auto found = std::find(values.begin(), values.end(), target);
```

Include `<algorithm>`. For ranges-based code in C++20, consider `std::ranges::count` and `std::ranges::find` when they improve readability.
