# Installation Checklist

Before deploying Blankspace:

- [ ] Confirm you are running a supported Wayland environment.
- [ ] Review the README and component dependencies.
- [ ] Back up existing files in `~/.config`.
- [ ] Check monitor, input, wallpaper, and application paths.
- [ ] Confirm optional components are installed separately when needed.
- [ ] Run the dry-run script before the installer.
- [ ] Verify each component after deployment.
