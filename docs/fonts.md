# Fonts

Blankspace uses JetBrains Mono Nerd Font for terminal and interface text, with IMD Grotesk used where the configuration calls for display typography.

On Arch Linux, JetBrains Mono Nerd Font can be installed with:

```bash
sudo pacman -S ttf-jetbrains-mono-nerd
```

IMD Grotesk is installed separately when required by the selected configuration.
