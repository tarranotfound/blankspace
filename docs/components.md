# Blankspace Components

Blankspace keeps each desktop component independent so parts of the rice can be installed, replaced, or tested without copying the entire setup.

## Components

- Hyprland — window management and keybinds
- Kitty — terminal and palette
- Fuzzel — application launcher
- Hyprlock — lock screen
- Noctalia — desktop shell and wallpaper environment
- Vibe — visual/background configuration
- Cava — audio visualizer
- btop — system monitor
- Neovim — editor configuration

When adapting Blankspace, start with the components you actually use and review paths before copying them into `~/.config`.
