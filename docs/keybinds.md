# Document Keybind Conventions

Notes for the Blankspace configuration and workflow.

## Workflow

- Keep compositor bindings in the Hyprland configuration as the source of truth.
- Use the keyboard as the primary navigation method.
- Keep launcher commands separate from window-management logic.
- Review application names and hardware-specific input settings before reusing bindings.

This keeps the documented workflow useful without duplicating the actual keybind definitions.
