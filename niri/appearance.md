# Blankspace Niri Appearance

Blankspace on Niri follows a lightweight monochrome approach with soft green accents.

## Visual direction

- Black or near-black background
- White and gray text
- Soft green for selected or active details
- Thin borders and restrained spacing
- No unnecessary blur, shadows, or heavy animations

## Suggested applications

- **Waybar:** keep modules minimal and avoid excessive animations.
- **Kitty:** use the existing Blankspace terminal theme.
- **Fuzzel:** keep the launcher compact with a simple monochrome palette.
- **Hyprlock:** use a clean clock and minimal information.
- **btop:** use a readable terminal theme with limited visual noise.
- **Wallpaper:** choose a dark, low-contrast image so text remains readable.

## Niri-specific notes

Niri uses scrolling columns instead of traditional floating workspace behavior. Keep gaps modest and avoid copying Hyprland-only settings directly. Test the layout and keybinds gradually after starting Niri.

## Hardware-friendly approach

For lower-power hardware:

1. Prefer static wallpapers.
2. Avoid multiple animated visualizers running at once.
3. Keep Waybar modules limited to useful information.
4. Disable optional startup programs you do not use.
5. Use a simple terminal-based workflow when possible.
