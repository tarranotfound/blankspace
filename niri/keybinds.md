# Blankspace Niri Keybinds

The default `config.kdl` uses `Mod` as the main modifier key, usually the Super/Windows key.

## Applications

| Keybind | Action |
|---|---|
| `Mod+Return` | Open Kitty |
| `Mod+D` | Open Fuzzel |
| `Mod+Alt+L` | Start Hyprlock |
| `Mod+Shift+E` | Quit Niri |
| `Mod+Q` | Close the focused window |

## Navigation

| Keybind | Action |
|---|---|
| `Mod+H` | Focus the column to the left |
| `Mod+J` | Focus the window below |
| `Mod+K` | Focus the window above |
| `Mod+L` | Focus the column to the right |

## Moving windows

| Keybind | Action |
|---|---|
| `Mod+Shift+H` | Move the column left |
| `Mod+Shift+J` | Move the window down |
| `Mod+Shift+K` | Move the window up |
| `Mod+Shift+L` | Move the column right |

## Customization

These bindings are a starting point. Review them before using the configuration, especially if they conflict with existing shortcuts or your preferred workflow.
